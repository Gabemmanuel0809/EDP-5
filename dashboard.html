What's inside

📝

Task Manager

Add tasks with titles, deadlines, and priority levels. A live progress bar shows how close each deadline is.

🍅

Pomodoro Timer

25-minute focus sessions with 5-minute breaks. Pause, resume, or reset anytime — stay in flow, avoid burnout.

⭐

XP & Levels

Complete tasks on time to earn XP. Miss deadlines and lose points. Level up by staying consistent.

🏆

Achievements

Unlock badges at milestones — first task, five tasks done, reaching level 3 and beyond.

📅

Calendar View

See which days have tasks due, color-coded by priority. Click any date to filter the task list instantly.

🔔

Deadline Alerts

Get warned when a task is due within 5 hours. Overdue tasks trigger an XP penalty automatically.

How it works

  1. 1
    Add a task

    Give it a title, pick a deadline date/time, and choose a priority level.

  2. 2
    Start a Pomodoro

    Hit Start on the timer. Work 25 minutes, then take a 5-minute break.

  3. 3
    Mark tasks done

    Complete tasks before the deadline to earn XP. Every point counts toward your next level.

  4. 4
    Level up

    100 XP per level. Unlock achievements along the way and watch your streak grow.
